Everything you answered is on the site. These are the last three things, in order.

Step 1 · Needs you

Connect the site’s calendar to Airbnb and Vrbo

The site already reads your Airbnb and Vrbo calendars, so booked nights are greyed out. This step is the other direction: when you record a direct booking on the site, Airbnb and Vrbo block those dates too. Paste this link into both, once:

https://theprosserhome.com/api/calendar.ics?key=717f3cca9851d461a34905eaba1d67c1b6ad06c4a3ac85da

Where to paste it

Airbnb: Calendar → Availability settings → Connect calendars → Import calendar. Paste the link and name it “The Prosser Home website”. Vrbo: Calendar → Import & export → Import calendar, same link. Both check it every few hours, so for a guest arriving within a day or two, also block the dates by hand.

Keep this link private. It only shows which nights are booked directly, with no names or guest details, and this page is hidden from search engines. If the link is ever shared, tell us and we’ll issue a new one.
