Cashclinic

AI-assisted intake that compresses patient history into a provisional doctor-ready report — for rapid physician review of cookie-cutter encounters. Cash-only. Processing layer only.

Prototype status. Not medical advice. Not a medical record of truth. Durable clinical records live in an existing HIPAA-compliant system (e.g. Amazing Charts), not here.

MVP · Intake → provisional report

v0.1 · interactable · browser · access gated

Free-text history and optional document upload. Structured provisional report for physician review. Downloadable Markdown. API-backed structuring via Claude. Shared access code required (authorized parties only).

Open the MVP →

Flow

  • Patient provides history (text + optional documents)
  • AI processing layer structures a provisional report — no fabrication of missing facts
  • Physician rapid review of cookie-cutter cases
  • Medical assistant verifies and checks out (later)
  • Storage remains in the physician's existing HIPAA provider

Principles

  • Processing layer only — not an EHR
  • Legal structure required — non-compliant paths are out of scope
  • Cash-only — no insurance billing in v0
  • Trusted AI — provisional labels; Runcible integration planned for non-fabrication trust
  • Easiest encounters first — high-throughput cookie-cutter cases

Status

Early build. End-point product criteria and patient journey (encounter → use → return) are being clarified with the physician partner. Weekly iteration.
