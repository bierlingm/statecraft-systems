# prosserhorsehotel-site

Serves **https://prosserhorsehotel.com** (and redirects www) from the existing `statecraft-systems`
Pages project. There is no second build: edit `public/prosserhorsehotel/` and push to master.

| prosserhorsehotel.com path | Served from (statecraft-systems.pages.dev) |
|---|---|
| `/`, `/boarding/`, … | `/prosserhorsehotel/preview/…` (website draft) |
| `/room`, `/room/*` | 301 to https://statecraft.systems/prosserhorsehotel/ (the client room lives on statecraft.systems only) |
| `/api/prosserhorsehotel/*` | forwarded to statecraft.systems → `prosserhorsehotel-intake` Worker |
| `www.` | 301 to apex |

- Zone `prosserhorsehotel.com` (id a5ea14e25168695b2bf1d8761b59e263), registered via Cloudflare Registrar 2026-10-13.
- Worker custom domains: `prosserhorsehotel.com`, `www.prosserhorsehotel.com` (DNS + certificates managed by Cloudflare).
- Every response carries `X-Robots-Tag: noindex, nofollow` while the site is a draft. Remove it (and the
  pages' meta robots) at launch. `/_archive` and `/prosserhorsehotel*` return 404 on this domain.
- Deployed via the Cloudflare API (no wrangler.toml). Redeploy only when this file changes.

## Going live (indexing switch)

The draft is `noindex` until Moritz decides to launch. **One-line switch:** in `src/index.js` set

```js
const INDEXABLE = true;
```

and redeploy the Worker. That drops the `X-Robots-Tag: noindex` header and strips each page's
`<meta name="robots" content="noindex,nofollow">` on the fly, and switches `/robots.txt` from `Disallow: /`
to the AI-search policy (see below). `/sitemap.xml` (all 7 pages) is already served by the Worker. Afterwards, also delete the meta robots
tags from `public/prosserhorsehotel/preview/**/index.html` so the source matches, update `LASTMOD`,
and submit `https://prosserhorsehotel.com/sitemap.xml` in Google Search Console and Bing Webmaster Tools.

Caching set by the Worker: `/assets/photos/*` and `/assets/social/*` 30 days; other `/assets/*` 1 day
(+ stale-while-revalidate); HTML `max-age=0, must-revalidate`.

## AI-search readiness (built 2026-10-27, takes effect at launch)

Generated by the Worker, only on prosserhorsehotel.com (never on statecraft.systems):

| Path | While `INDEXABLE = false` (now) | After launch |
|---|---|---|
| `/robots.txt` | `User-agent: * / Disallow: /` | Allows OAI-SearchBot, ChatGPT-User, PerplexityBot, Claude-SearchBot, Claude-User, Bingbot, Googlebot and `*`; blocks GPTBot, ClaudeBot, Google-Extended, CCBot, anthropic-ai, Applebot-Extended; `Sitemap:` line |
| `/llms.txt` | served, `X-Robots-Tag: noindex` | plain summary + links to every page, plus what is not yet published |
| `/feed.json` | served, `X-Robots-Tag: noindex` | JSON Feed 1.1 of the 7 pages (title, url, summary, date_modified, base rates) |
| `/sitemap.xml` | served, `X-Robots-Tag: noindex` | ready for Bing Webmaster Tools / Search Console |

The llms.txt / feed.json text lives in `FEED_ITEMS` in `src/index.js` and is copied from the pages. Keep it in sync
when page content changes (and bump `UPDATED` / `LASTMOD`). Pages carry a dated "Quick answer" block at the top
and JSON-LD (LodgingBusiness on home, Service + Offers on boarding / camping / fifth wheel) that matches the visible text.

The site has no analytics, so there is nothing to tag ChatGPT referrals (`utm_source=chatgpt.com` / referrer
`chatgpt.com`) in yet. If analytics are added at launch, segment that source there.
